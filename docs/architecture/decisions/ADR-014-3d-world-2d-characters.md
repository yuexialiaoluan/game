# ADR-014：3D 世界 + 2D 像素角色

- 问题：世界场景与角色表现采用何种组合，才能满足“类似现代 2.5D 像素 JRPG”的目标。
- 候选方案：纯 2D 地图；纯 3D 全场景含 3D 角色；3D 世界 + 2D 像素角色；混合 2D 地图 + 3D 特效。
- 最终方案：3D 环境场景 + 2D 像素角色 + 2D 骨骼/分层 + 3D 灯光。
- 选择原因：3D 环境天然提供遮挡、高低差、桥梁/台阶/坡地、光照、动态阴影、景深与后处理；2D 像素角色保留高清像素表现与成熟的分层/骨骼/装备系统，兼顾成本与风格。
- 优缺点：优点是空间层次与光照质量高、角色可长期复用 2D 管线；缺点是需处理 2D/3D 深度融合、billboard 与光照一致性、摄像机与像素稳定性。
- 未来影响：Camera 采用 3D 正交/透视；World 采用 3D Streaming；Character/Appearance/Equipment/Animation 保持 2D 部件与骨架，作为 billboard 放入 3D 场景；Asset Pipeline 拆为 3D 环境与 2D 角色双管线。
