# Camera 系统（3D 摄像机）

## 职责
3D 场景摄像机架构，支持 2.5D 呈现与多种情境。

## 投影
- 默认：3D 正交投影（保持像素稳定，便于 2.5D 融合）。
- 可选：适当透视投影，用于对话、Cutscene 或特殊镜头。

## 模式
世界探索、战斗、地下城、对话、Cutscene。

## 能力
- 镜头跟随、缩放、限制。
- 支持光照、动态阴影、景深、后处理与 2D VFX 的合成。
- 2D 角色 billboard 始终朝向或按规则对齐摄像机。

## 设计
- `CameraSystem` 管理模式切换与参数。
- 各系统请求镜头目标/约束，Camera 负责插值与限制。
- 渲染设置（正交/透视、景深、后处理）由渲染配置统一控制。

## 依赖
World/Scene、Combat、Dialogue、Cutscene、Input（视情况）。
