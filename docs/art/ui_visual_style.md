# UI 视觉规范

## 风格
现代、半透明、玻璃质感、细线、科技感、蓝白基调。
不复制任何商业游戏 UI。

## 资源分类
Panels、Frames、Icons、Buttons、Background、Portrait Frames、Skill Icons、Item Icons、Status Icons。

## 原则
- UI 资源与 UI 逻辑分离（场景/主题在 `ui/`，原始资源在 `assets/ui/`）。
- 图标使用统一尺寸与线宽；状态图标语义清晰。

## 命名
- `ui_panel_001`、`ui_icon_skill_001`、`ui_icon_item_001`、`ui_frame_portrait_001`。

## 存储
- `assets/ui/`。
