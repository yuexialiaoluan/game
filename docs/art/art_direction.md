# Art Direction（总体美术方向）

## 核心方向
目标视觉不是纯 2D RPG，而是“类似现代 2.5D 像素 JRPG”：
- 3D 环境场景 + 2D 像素角色 + 2D 角色分层 + 2D 骨骼/部件绑定。
- 3D 正交/适当透视摄像机 + 3D 灯光 + 动态阴影 + 景深 + 后处理 + 2D VFX。

## 分层原则
- 世界：3D 空间中的 Terrain / Building / Prop / Nature / Dungeon / Background / Foreground。
- 角色：2D 像素 Sprite Part，通过 Skeleton / Bone Attachment 组合，在 3D 世界中以 billboard 方式呈现。
- UI：现代、半透明、玻璃质感、科技感，蓝白基调。

## 统一一致性
- 3D 环境采用低多边形/风格化建模与贴图，使其与像素角色在“密度、比例、配色”上协调。
- 2D 角色保持统一像素密度与 Nearest 采样。
- 3D 光照/阴影/景深作用于世界，2D 角色按规则参与光照或保持统一受光，避免割裂。

## 空间层次
- 背景（远景）、中景（可玩区域）、前景（遮挡物）。
- 高低差、桥梁、台阶、坡地、建筑遮挡与前景遮挡由 3D 深度自然处理。

## 原创约束
- 参考现代 2.5D 像素 JRPG 的理念，不复制任何商业游戏的素材、角色、场景或 UI。
